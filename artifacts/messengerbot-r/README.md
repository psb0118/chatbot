# 폰 전용 플로버 봇 (메신저봇 R)

**서버·데이터베이스·Render·시크릿·인터넷 전부 필요 없습니다.**
폰에 메신저봇 R이 설치되어 있으면 [`flover-bot.js`](flover-bot.js) 하나로 끝납니다.

| | 이 방식 | `artifacts/api-server` (서버 방식) |
| --- | --- | --- |
| 필요한 것 | 폰 + 메신저봇 R | 서버 호스팅 + Postgres + 시크릿 |
| 기록 저장 | 앱 로컬 `flover_data.json` | Postgres |
| 웹 대시보드 | 없음 | 있음 |
| 데이터 수명 | 앱 삭제·폰 초기화 시 소실 | DB에 보존 |

## 붙이는 순서

1. 메신저봇 R → **봇 추가**
2. 봇 옵션
   - `레거시 API 사용` → **체크 해제** (이 스크립트는 API2라 `bot.addListener`로 받습니다)
   - `통합된 매개변수 사용` → **체크 해제**
3. 스크립트의 `ADMIN_SETUP_CODE`를 **본인만 아는 값으로 변경** 후 전체 붙여넣기
4. 봇 스위치 ON → 방에서 `!도움말`

> `ADMIN_SETUP_CODE`를 그대로 두면 `!관리자등록`이 거부됩니다. 실수로 잠기지 않게
> 일부러 막아 둔 것입니다.

## 명령어

| 명령 | 동작 |
| --- | --- |
| `!가입 <닉네임> <비밀번호>` | 가입 후 자동 로그인 |
| `!로그인` / `!로그아웃` | 세션 관리 (앱을 끄면 다시 로그인) |
| `!내정보` | 레벨·티어·EXP·출석 횟수 |
| `!출석` | 한국 시간 자정 기준 하루 1회, +50 EXP |
| `!랭킹` | 누적 EXP 상위 5명 |
| `!퀴즈` / `!노래퀴즈` | 퀴즈 출제 |
| `!힌트` | 진행 중인 퀴즈 힌트 + 남은 시간 |
| `!정답 <답>` | 정답 제출, 정답 시 +30 EXP |
| `!멤버` / `!공지` / `!도움말` | 멤버 목록, 공지, 명령 안내 |

관리자(`!관리자등록 <코드>`): `!회원목록`, `!회원조회 <닉네임>`, `!밴 <닉네임>`,
`!밴해제 <닉네임>`, `!공지등록 <문구>`, `!백업`

## 고칠 곳

스크립트 위쪽 두 블록만 손대면 됩니다.

- `CONFIG` — 관리자 코드, EXP 양, 쿨다운, 퀴즈 시간
- `MEMBERS` / `SONGS` / `QUIZZES` — 멤버 이름, 노래 목록, 퀴즈 목록

## 알아 둘 점

- **기록은 폰 안에만 있습니다.** `!백업`은 같은 폰에 파일을 만들 뿐이라, 폰을
  초기화하면 함께 사라집니다. 중요한 기록이면 주기적으로 밖으로 옮겨 두세요.
- 닉네임을 바꾸면 앱이 `msg.author.hash`를 주는 경우에만 같은 사람으로 인식됩니다.
  `hash`가 없는 구버전 앱에서는 **닉네임이 곧 신원**이라, 이름을 바꾸면 새 사람이 됩니다.
- 채팅만으로 레벨이 오르지 않도록 **5초 쿨다운, 하루 200 EXP 상한**을 두었습니다.
- 퀴즈 정답은 공백·문장부호·대소문자를 무시하고 비교합니다.
- 비밀번호는 로컬 파일에 그대로 남지 않게 해시해서 저장하지만, 암호학적으로
  안전한 수준은 아닙니다. 다른 곳에서 쓰는 비밀번호는 넣지 마세요.
