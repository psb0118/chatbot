# 폰 전용 플로버 봇 (메신저봇 R)

**서버·데이터베이스·Render·시크릿·인터넷 전부 필요 없습니다.**
폰에 메신저봇 R이 설치되어 있으면 [`flover-bot.js`](flover-bot.js) 하나로 끝납니다.

| | 이 방식 | `artifacts/api-server` (서버 방식) |
| --- | --- | --- |
| 필요한 것 | 폰 + 메신저봇 R | 서버 호스팅 + Postgres + 시크릿 |
| 기록 저장 | 앱 로컬 `flover_data.json` | Postgres |
| 웹 대시보드 | 없음 | 있음 |
| 가입 방식 | `!가입` 한 번 → 6자리 회원번호 | 웹 회원가입 + 기기 연동 |

## 붙이는 순서

1. 메신저봇 R → **봇 추가**
2. 봇 옵션
   - `레거시 API 사용` → **체크 해제** (이 스크립트는 API2라 `bot.addListener`로 받습니다)
   - `통합된 매개변수 사용` → **체크 해제**
3. 스크립트 전체 붙여넣기 → 봇 스위치 ON → 방에서 `!사용법`

## 명령어

비밀번호도 로그인도 없습니다. `!가입` 한 번이면 그 방의 그 닉네임으로 계속 씁니다.

| 명령 | 동작 |
| --- | --- |
| `!가입` | 회원가입. 닉네임과 6자리 회원번호만 발급 |
| `!정보` | 이름·회원번호·최애·입덕일 |
| `!레벨 [회원번호]` | 그 회원번호의 레벨. 번호를 빼면 내 레벨 |
| `!연동 <회원번호>` | 지금 닉네임을 그 회원번호 기록에 다시 연결 |
| `!최애` / `!최애등록 <멤버>` | 최애 멤버 조회 / 등록 (이름 일부만 써도 됩니다) |
| `!입덕` / `!입덕등록 <날짜>` | 입덕일 조회 / 등록 (`2021-05-04`, `2021.5.4`, `20210504` 모두 허용) |
| `!추천곡` | 추천곡 한 곡 |
| `!이름변경 <이름>` | 봇에서 부를 이름 변경 |
| `!사용법` | 명령어 목록 + 추가 명령어 목록 |

`!사용법`의 **추가 명령어** 칸은 스크립트 위쪽 `EXTRA_COMMANDS` 배열 내용이 그대로 나옵니다.
지금은 예시로 `!레벨` 한 줄이 들어 있고, 여기에 한 줄씩 더 적으면 그 자리에 바로 뜹니다.

```js
var EXTRA_COMMANDS = [
  '· !레벨 회원번호 — 그 회원번호의 레벨 보기'
];
```

## 고칠 곳

스크립트 위쪽 두 블록만 손대면 됩니다.

- `CONFIG` — 이름 길이, 입덕일 최소 날짜
- `MEMBERS` / `SONGS` / `EXTRA_COMMANDS` — 멤버 이름, 추천곡 목록, 사용법 문구

## 알아 둘 점

- **기록은 폰 안에만 있습니다.** 앱을 지우거나 폰을 초기화하면 함께 사라집니다.
  백업 명령은 없으니, 중요한 기록은 주기적으로 밖으로 옮겨 두세요.
- 닉네임을 바꾸면 앱이 `msg.author.hash`를 주는 경우에만 같은 사람으로 이어집니다.
  `hash`가 없는 구버전 앱에서는 **닉네임이 곧 신원**이라, 이름을 바꾸면 새 사람이 됩니다.
  그때는 미리 적어 둔 회원번호로 `!연동 <회원번호>` 하면 기록이 돌아옵니다.
- 최애·입덕일은 사람마다 하나씩만 저장됩니다. 다시 등록하면 덮어씁니다.
- 레벨은 **입덕일로만** 매깁니다. 입덕 30일마다 1레벨이고, 입덕일이 없으면 레벨도 없습니다.
  채팅량이나 출석으로는 오르지 않습니다(그 기능들은 뺐습니다).
